# Kahve Fincanında Yüzme Yapan Kedi Simülatörü

## Giriş (Ciddiye Alınız)

Bu proje, insanlığın en büyük gizemlerinden birini çözmek için yola çıkmıştır: Bir kedi, kahve fincanının içinde yüzebilir mi?

Cevap: Evet. Ve hayır. Ve belki. Bilim henüz karar vermedi ama biz verdik.

### Özellikler
- Gerçek zamanlı ASCII kedi yüzme simülasyonu
- Rastgele "başarı" veya "felaket" sonuçları
- Kahve sıcaklığı hesaplaması (tamamen uydurma)
- Sonsuz döngü riski (kullanıcı uyarılır)

### Nasıl Çalıştırılır?
```bash
python kedi.py
```

Eğer Python yoksa, kedi de yok. Kader.

### Bilimsel Kanıtlar
Hiç yok. Ama çok ciddi gözüküyor.

### Uyarı
Bu simülatör, gerçek kedilere uygulanmamalıdır. Kahve için de öyle.
